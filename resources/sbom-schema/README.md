# CycloneDX validation resources

These are unmodified CycloneDX 1.6 JSON schemas, compressed with gzip for offline developer-tool validation. `source.json` pins the upstream commit, URLs, uncompressed sizes and SHA-256 digests. The validator checks those digests before using the schemas.

The original upstream license is retained in [LICENSE](LICENSE). These third-party files keep their original terms; Folio's noncommercial terms do not replace them. They are developer validation data and are not bundled into Folio.app.

Upstream: [CycloneDX specification, pinned commit](https://github.com/CycloneDX/specification/tree/55343ba19dee1785acf1ce9191540d5fd7b590db/schema).
