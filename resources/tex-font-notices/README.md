# Original notices for included compiler fonts

These third-party fonts and support files retain their original licenses. Folio's noncommercial license applies to Folio's original work, not to these fonts. The accompanying notice files are unmodified copies. Their filenames identify the font family or the applicable license text.

| Included fonts | Original notices and terms |
| --- | --- |
| Latin Modern text fonts | `lm-GUST-FONT-LICENSE.TXT`, the original Latin Modern README and manifest, and `LPPL-1.3c.txt` |
| Latin Modern Math | `lm-math-GUST-FONT-LICENSE.txt`, the original math README and manifest, and `LPPL-1.3c.txt` |
| Roboto, Roboto Condensed and Roboto Slab | `roboto-COPYRIGHT.txt`, `roboto-LICENSE.txt` (Apache 2.0) and `roboto-README`; support files use LPPL |
| Source Sans Pro | `sourcesanspro-LICENSE.txt` (OFL 1.1) and `sourcesanspro-README.md`; support files use LPPL |
| Font Awesome 5 Free | `fontawesome5-README.md`, `FontAwesome-publisher-LICENSE.txt` and `OFL-1.1.txt`; TeX support uses LPPL 1.3c |

All 63 font binaries, and 48 accompanying support files in this compiler bundle, match the following TeX Live distributions exactly. Folio includes selected files without changing their contents. Full original distribution archives and their documentation are available at these locations:

- [Latin Modern fonts](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2021/tlnet-final/archive/lm.tar.xz) and [documentation](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2021/tlnet-final/archive/lm.doc.tar.xz), TeX Live revision 61719.
- [Latin Modern Math](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2021/tlnet-final/archive/lm-math.tar.xz) and [documentation](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2021/tlnet-final/archive/lm-math.doc.tar.xz), revision 36915.
- [Roboto](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2021/tlnet-final/archive/roboto.tar.xz) and [documentation](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2021/tlnet-final/archive/roboto.doc.tar.xz), revision 54512.
- [Source Sans Pro](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2021/tlnet-final/archive/sourcesanspro.tar.xz) and [documentation](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2021/tlnet-final/archive/sourcesanspro.doc.tar.xz), revision 54892.
- [Font Awesome 5](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2021/tlnet-final/archive/fontawesome5.tar.xz) and [documentation](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2021/tlnet-final/archive/fontawesome5.doc.tar.xz), revision 59462.

The original Font Awesome publisher notice comes from [release 5.15.3's source](https://github.com/FortAwesome/Font-Awesome/blob/d79d85c3fad85ad1885e87ed558f4afd6fce8289/LICENSE.txt). It describes fonts, code and standalone icons separately. Only the font terms apply to the included Font Awesome font files. The TeX Live font copies differ from that upstream archive, so the source audit matches the TeX Live distribution rather than claiming an unchanged upstream font build.

The full [LPPL 1.3c](https://www.latex-project.org/lppl/lppl-1-3c.txt) and [OFL 1.1](https://github.com/spdx/license-list-data/blob/d46e94e2c78ceede1cfc63cfa0396472d2798d4c/text/OFL-1.1.txt) texts are included alongside the original grants and copyright notices. Original font files also retain their embedded copyright and naming records.

This folder covers these compiler fonts and matching support files. Other TeX resources, the application interface fonts, compilers and libraries have separate terms. It is not a complete application SBOM. Folio contributors provide support for Folio; the upstream font authors do not maintain or endorse this application. Source identities, file mappings and reproduction commands are recorded in the Folio repository's `resources/tex-font-sources.lock.json` and `docs/LICENSING.md`.
