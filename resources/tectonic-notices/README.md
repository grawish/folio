These are unchanged original texts for Tectonic 0.17.0, its source families, resolved Rust executable build closure, matching Rust toolchain and native build ports. The app license does not replace any of these terms.

There are 657 source references to 255 distinct original texts. Identical texts are stored once; the table below preserves every component and original filename. `SOURCES.json` records exact archive URLs, hashes and original paths. Some source/build collections include host tools and unused code; inclusion here does not claim that every component is linked into the final executable. Biber/Perl, per-file grants, corresponding-source obligations and the complete app redistribution audit remain separate.

The source repository stores the original bytes losslessly in `ORIGINALS.json.gz`. Packaging expands and verifies the original text files alongside this guide. No network access or Rust build is needed to package them. To reproduce the collection after running the existing source collectors:

```sh
python3 scripts/collect-tectonic-notices.py --materials /path/to/artifacts/license-materials
```

The collector rechecks all 319 retained original archives and each notice. Supplemental texts match their exact-commit source lock. It writes an immutable result under `artifacts/license-materials/tectonic-notices/`; it does not change existing source collections or app/compiler bytes.
