# Security reports

Do not post API keys, personal resumes, provider sessions, or exploitable private data in a public issue. Use GitHub's private vulnerability reporting on this repository when it is enabled. If it is unavailable, open an issue asking for a private contact without describing exploit details.

Folio is a development preview. The renderer uses a narrow native bridge; compiler jobs use local snapshots and macOS Seatbelt restrictions. These controls do not yet provide hard process-tree memory or disk quotas. See the release audit for known limits.

When reporting a problem, include the app/source version, macOS version, a synthetic reproduction, and the operation that failed. Review logs and screenshots before sharing them. No support-bundle generator or automatic redaction is currently available.
