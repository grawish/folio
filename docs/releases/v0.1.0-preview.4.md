# Folio 0.1.0 preview 4 — faster editing and chat model selection

First downloadable Apple silicon Mac preview. Download `Folio-0.1.0-preview.4-mac-arm64.dmg`, open it, and drag Folio to Applications. No separate TeX installation is required. This build is unsigned and not notarized; macOS may block its first launch. Automatic updates are not implemented.

## Changes

- Select Auto, the connection default, or a specific model beside Send. Selections are remembered for each connection.
- Auto uses configurable Fast and Capable roles within your current Codex, Claude Code, OpenAI, Anthropic or compatible API connection. Each response reports the model used and any escalation.
- Narrow text edits with a current, matching PDF can finish with one model call, one candidate compile and no image rendering. Layout changes and PDF feedback still receive visual review.
- Atomic exact-match patches reduce generated output. Warm Codex processes, PDF provenance checks and image caching avoid repeated work.
- History distinguishes **Built successfully** from **Visually checked**.

The controlled synthetic benchmark reduced median harness time from 181.9 ms to 93.3 ms (48.7%). These are fixed-delay fixtures, not live-provider latency measurements; see [the performance report](../HARNESS_PERFORMANCE.md).

## Downloads and provenance

The release carries the DMG, an equivalent application ZIP, `SHA256SUMS`, a build provenance record, package verification evidence and a third-party materials archive. GitHub's source archives identify the tagged application source. Collected npm/Electron notices, the npm SBOM, pinned compiler sources, locked Rust crates and compiler build evidence are also inside the app at `Contents/Resources/third-party-materials`.

The production redistribution audit is still incomplete; the included inventories describe their coverage and remaining gaps. This preview does not claim completed native-library/TeX/Biber dependency review, signing, notarization, automatic updates or support for every macOS version. Windows, Linux and Intel Macs are outside this release's scope. See [licensing](../LICENSING.md) and the [release audit](../RELEASE_GAP_AUDIT.md).

## Validation and reproduction

The release's `provenance.json`, `verification.json` and `native-tests.json` record the exact source commit, artifact digests and packaged native test results. Source validation includes 225 passing unit/protocol tests, typechecking and the production build. Native workflows use isolated synthetic projects and run sequentially; no real resumes or API credentials are included.

Prepare the runtime with `npm run setup`, collect notices with `node scripts/collect-license-materials.mjs`, compiler source materials with `node scripts/collect-runtime-license-materials.mjs`, and Rust sources with `python3 scripts/collect-rust-license-materials.py`. The compiler-build evidence collector is documented in [compiler provenance](../COMPILER_PROVENANCE.md). Run `npm run build`, then Electron Builder with the release's `preview-builder.json`, `--mac --arm64 --publish never`, and `CSC_IDENTITY_AUTO_DISCOVERY=false`. This configuration includes the collected third-party materials. Run `node scripts/test-mac-release.mjs release` followed by `node scripts/verify-mac-package.mjs release` to check the packaged app and disk image.
