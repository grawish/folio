# Folio 0.1.0 preview 5 — current unsigned Apple silicon build

Download `Folio-0.1.0-preview.5-mac-arm64.dmg` or
`Folio-0.1.0-preview.5-mac-arm64.zip`. This is an **unsigned, unnotarized**
Apple silicon preview. It is not Developer ID signed and may require an explicit
Gatekeeper bypass. Do not treat it as a production release.

## What changed

- Bounded imported-project and pack-download free-space admission before any
  recovery/destination or download write. A 32 MiB margin is required; valid
  retained pack partial bytes reduce only the remaining-download requirement.
- APFS low-storage control: a disposable 64 MiB APFS image forces `ENOSPC`
  during journaled save and staged import, checks original/destination bytes,
  then frees space and verifies the exact retry/resume.
- Biber normal and tool-mode runtime smoke now uses tracked fixtures, so it
  runs without ignored local source-material caches.
- Codex and Claude Code source-build acceptance workflows each completed a
  synthetic annotated edit, local compile/review, export, save and reopen.
  Codex uses the account-supported `gpt-5.5` model; an unsupported personal
  CLI default is reported by the provider rather than silently changed.
- Expanded provenance/notice controls for Biber, Tectonic native linkage,
  TeX/font grant-review queue and unsigned-candidate materials indexing.

## Verification

The tagged source passed GitHub source CI:

- 553 TypeScript unit tests locally before release preparation;
- current source CI: formatting, source tests, build, APFS low-storage control,
  website and generated-Skill checks;
- packaged Apple-silicon smoke compiled bundled templates, imported packages,
  fonts and Biber locally;
- downloaded source/docs/Skill release archives pass their published SHA-256
  manifest and ZIP integrity checks.

The app archives include `SHA256SUMS`, built app/DMG/ZIP verification, and an
unsigned-candidate materials index. These checks verify local bytes and do not
replace Apple signing, notarization, a clean consumer installation, reference
hardware, a complete redistribution review, or a signed-update workflow.

## Security and distribution limits

No free alternative provides trusted public macOS distribution signing:

- Ad-hoc and self-signed certificates are not trusted by Gatekeeper.
- Developer ID and notarization require Apple Developer Program membership.
- This preview has no automatic updates and no production publisher identity.
