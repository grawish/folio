Folio is a chat-first LaTeX resume studio for Apple silicon Macs. This prerelease publishes the reviewed source, screenshot tutorials, and reusable documentation skill.

Included assets:

- Source archive from the tagged commit, including tests and pinned dependency metadata.
- Documentation and screenshot demo archive.
- Standalone `folio-resume` skill with its guide references.
- SHA-256 checksums and build provenance.

Build instructions are in README.md. This is a **source preview**; it does not include a signed/notarized Mac installer. Complete binary redistribution materials and SBOM, real Developer ID signing/notarization, supported-Mac acceptance, signed-to-signed updates and other requirements remain open in `docs/RELEASE_GAP_AUDIT.md`.

The guides include 37 screenshot demos and ten walkthroughs. AI fixture demos are labeled. One real Claude Code subscription workflow with a PDF note, compilation, visual review, save/export and reopen has passed in the source-built app; real BYOK, broader account/model coverage and signed-package live-provider acceptance remain unverified. Local compilation works without AI; chatting sends relevant source and PDF images to the selected provider.

Original Folio work uses PolyForm Noncommercial 1.0.0. This is a noncommercial, source-available community project. Third-party materials retain their own licenses.
