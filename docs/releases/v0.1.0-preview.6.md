# Folio v0.1.0-preview.6

First Windows and Linux preview builds.

## Downloads

- **Windows x64:** `Folio-0.1.0-preview.6-win-x64-setup.exe` (installer) or `Folio-0.1.0-preview.6-win-x64.zip`.
- **Linux x64:** `.deb`, `.AppImage` and `.tar.gz`.
- Checksums: `SHA256SUMS-win.txt`, `SHA256SUMS-linux.txt`.

The Apple silicon DMG remains [preview 5](v0.1.0-preview.5.md) until a Mac candidate is qualified from this source.

## What changed

- PDF compiling works on Windows and Linux with the same pinned Tectonic 0.17.0, Biber 2.17 and locked `folio-core-v1` resource bundle as macOS.
- Linux builds run under kernel resource limits; Windows builds use Tectonic untrusted mode with a timer and process-tree stop. See [Windows and Linux](../WINDOWS_LINUX.md).
- Projects saved on a Mac open and compile on Windows/Linux (and back) when the compiler identity matches.
- Support bundles report Windows/Linux and x64 instead of "unsupported".

## Limitations

- Unsigned: Windows SmartScreen warns on first launch; Linux packages are not GPG-signed.
- No automatic updates on Windows/Linux; resource packs are Apple silicon only for now.
- Per-platform SBOM and the native UI test suites have not been run for Windows/Linux.
